- les dossiers de code, rangés par techno et par cours.

## Site portfolio

Le site est fait en HTML, CSS et JavaScript simple.

Il présente :

- mon profil étudiant en informatique ;
- ma stack technique ;
- mes projets ;
- ma progression ;
- mes objectifs en cours.

Pour ouvrir le site :

```txt
index.html
```

Ou avec un petit serveur local :

```bash
python3 -m http.server 8000
```

Puis :

```txt
http://localhost:8000
```
