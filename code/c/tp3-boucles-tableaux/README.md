# TP3 - Boucles et tableaux

Objectif du TP : utiliser les boucles et manipuler des tableaux en C.

## Ce que j'ai fait

- utiliser des boucles `for` ;
- afficher des formes dans le terminal ;
- parcourir un tableau ;
- rechercher une valeur ;
- compter des occurrences ;
- calculer un minimum, maximum et une moyenne ;
- tester si un tableau est trié ;
- manipuler des tableaux à deux dimensions.

## Exercices travaillés

- afficher un carré avec des `*` ;
- afficher des triangles ;
- afficher un tableau ;
- tester si une valeur est présente ;
- décaler les valeurs d'un tableau ;
- afficher une matrice ;
- afficher une diagonale ;
- calculer la somme d'une colonne.
