# TP1 - Introduction au langage C

Objectif du TP : prendre en main le langage C et la compilation dans le terminal.

## Ce que j'ai fait

- créer un dossier de TP ;
- compiler avec `gcc` ;
- créer un exécutable ;
- écrire des procédures simples ;
- tester les affichages dans le terminal.

## Exercices travaillés

- afficher `Bonjour` ;
- afficher plusieurs lignes ;
- lire des entiers au clavier ;
- afficher deux entiers ;
- calculer et afficher une somme ;
- utiliser des paramètres dans une procédure ;
- tester les procédures une par une.
