# TP2 - Fonctions et conditionnelles

Objectif du TP : utiliser les conditions et écrire des fonctions qui retournent une valeur.

## Ce que j'ai fait

- utiliser `if` et `else` ;
- comparer des entiers ;
- écrire des fonctions avec `return` ;
- écrire des fonctions de test qui retournent `TRUE` ou `FALSE` ;
- tester les résultats avec plusieurs cas.

## Exercices travaillés

- afficher le maximum entre deux nombres ;
- tester si un nombre est plus grand ou plus petit ;
- vérifier si trois nombres sont triés ;
- trouver le maximum entre trois nombres ;
- tester si au moins deux paramètres sont égaux ;
- comparer une somme et un produit ;
- créer un petit menu dans le `main`.
