# TP4 - Paramètres, chaînes et fonctions

Objectif du TP : mieux découper un programme et manipuler des chaînes de caractères.

## Ce que j'ai fait

- passer des tableaux en paramètre ;
- manipuler des tableaux de caractères ;
- manipuler des tableaux de chaînes ;
- lire des mots depuis un fichier ;
- utiliser la boucle `while` ;
- écrire des fonctions plus longues ;
- réfléchir à la structure d'un programme.

## Exercices travaillés

- carré magique ;
- somme de lignes, colonnes et diagonales ;
- test de carré magique ;
- taille du plus grand mot ;
- filtrage de mots ;
- remplacement de caractères ;
- comptage de lettres ;
- inversion de mots ;
- base du jeu du pendu.
