Objectif : créer un petit jeu où l'utilisateur doit deviner un nombre.

## Ce que j'ai travaillé

- compteur de tentatives ;
- tableau pour garder l'historique ;
- lecture d'une valeur dans un `input` ;
- conditions `if`, `else if`, `else` ;
- bouton pour recommencer.
